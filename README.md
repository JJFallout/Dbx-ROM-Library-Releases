# Dropbox ROM Library releases

This public repository hosts signed Windows installers, update manifests and checksums for Dropbox ROM Library. Application source is maintained separately in a private repository.

No installer has been published here yet. The first release will appear under Releases after signing and release validation are complete. The current desktop application is a prototype; it is not yet a replacement for an existing live installation.

Published update releases contain only the installer, its signature, `latest.json` and `SHA256SUMS`. Private credentials, library data, ROMs, firmware, logs, signing keys and application source do not belong in this repository.

Configured standalone builds verify signed updates before installation. Initial installation and migration are separate from subsequent in-app **Update and restart** operations.
